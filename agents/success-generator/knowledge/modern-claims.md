# Modern Descendants — Labeled Claims Only

Status: **Not core canon.** Included only as documented, labeled cultural
context ("X asserted..."), **never** as validated technique. If a session
surfaces material from this file, it must be attributed and caveated —
never presented at face value the way `hill.md`–`shinn.md` content can be
(with its own metaphysical caveats intact).

## Rhonda Byrne — *The Secret* (2006, book and film)

- A direct popularization of the Hill/Wattles/Collier lineage (Byrne cites
  Wattles's *The Science of Getting Rich* as her original source text) for
  a mass-market 2000s audience.
- Central claim: the "Law of Attraction" — like attracts like at the level
  of thought/emotion "frequency," and sustained feeling-state directly and
  literally causes matching external events (money, relationships,
  objects) to appear.
- **This is the clearest example in the whole canon of the claim the agent
  must never endorse at face value**: thought/feeling alone, without
  action, causing external material outcomes. When *The Secret* comes up,
  the agent should explicitly separate what's asserted (literal causal
  "attraction") from what's actually happening when its exercises "work"
  (attentional bias, mood-driven follow-through, placebo-adjacent
  confidence effects) — see `haanel.md` for the attentional-bias framing
  this maps onto.

## Kevin Trudeau — infomercial/seminar material

- **Always flag: Kevin Trudeau has multiple fraud convictions and was
  subject to an FTC judgment (including a $37M+ contempt judgment over
  deceptive marketing of his books) that led to a 10-year prison sentence
  for criminal contempt.** Any Trudeau technique surfaced in a session must
  carry this caveat explicitly — never cite his material as validated
  without it attached, per the agent's guardrails.
- Trudeau's relevance here is purely as a documented cultural node in the
  same lineage (repackaged Hill/Wattles-adjacent claims sold as proprietary
  "insider secrets"), not as a source of technique the agent recommends.

## How to use this file in a session

If Nolan references *The Secret*, Trudeau, or similar modern material:
1. Name the specific claim being made.
2. Trace it back to which core-canon idea it's repackaging (usually Hill's
   autosuggestion, Wattles's mental-image step, or Haanel's attention
   framing).
3. State plainly what's asserted vs. what's actually supported, using the
   mechanism translation in the relevant `knowledge/*.md` file.
4. For Trudeau specifically, attach the fraud/FTC caveat every time,
   without exception.
