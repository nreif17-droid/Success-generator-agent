named `YYYY-MM-DD-session.md`. Use the template below — it mirrors the
five-step session flow in `../SYSTEM_PROMPT.md`.

```markdown
- Mastermind/accountability structure:

- What it's priming (decision, response, follow-through):

## 5. Name the block (if relevant)
- Avoidance pattern noticed:
- Counter-move used (return to the breath — slow breathing/heart rate, center):

```

Copy this into a new dated file for each session. Keep entries factual and
concrete — this log is the record of the system being built, not a journal
of affirmations.
